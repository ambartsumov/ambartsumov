## What I build

I like work that can be inspected end to end: the data it starts from, the constraints it meets, the system it becomes, and the evidence that it works. My current focus:

- **Real-time voice AI** — telephone-grade ASR → LLM → TTS pipelines, latency budgets, hand-off to a human operator.
- **Low-resource languages** — building speech and language models where little data exists; Turkmen is my working example, and the methods carry over to any of the world's ~7,000 languages.
- **Agents and tooling** — practical agents, evaluation, and production-minded backend infrastructure.
